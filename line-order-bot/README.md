# LINE Order Bot — บอทเก็บออเดอร์ + สลิปโอนเงิน สำหรับแม่ค้าออนไลน์

บอทขายของอัตโนมัติบน LINE แบบ **multi-tenant**: โค้ดชุดเดียว รันเซิร์ฟเวอร์เดียว
รองรับร้านค้าได้หลายร้าน แต่ละร้านมี LINE OA, สินค้า, PromptPay และโควตาของตัวเอง
— นี่คือหัวใจของโมเดล "สร้างครั้งเดียว ขายหลายคน"

## ลูกค้า (ผู้ซื้อ) เจออะไร

1. ทักแชทร้าน → บอทต้อนรับ แนะนำให้พิมพ์ "เมนู"
2. `เมนู` → เห็นรายการสินค้าพร้อมรหัสและราคา
3. `สั่ง 1 2` → หยิบสินค้ารหัส 1 จำนวน 2 ชิ้นลงตะกร้า (สั่งเพิ่มได้เรื่อยๆ)
4. `ยืนยัน` → ได้เลขออเดอร์ + สรุปยอด + **QR PromptPay ที่ล็อกยอดโอนแล้ว**
5. โอนเงินแล้วส่งรูปสลิปเข้าแชท → บอทรับสลิป แจ้งเจ้าของร้านตรวจ
6. เจ้าของร้านพิมพ์ `อนุมัติ OD00001` → ลูกค้าได้รับข้อความยืนยันอัตโนมัติ

ถามคำถามทั่วไป (ค่าส่ง, เวลาเปิดร้าน ฯลฯ) บอทตอบเองจาก FAQ ที่ตั้งไว้ต่อร้าน

## ติดตั้ง

```bash
cd line-order-bot
npm install
cp data/tenants.example.json data/tenants.json   # ใส่ค่าจริงของร้านแรก
cp .env.example .env                             # ตั้ง BASE_URL (https)
npm start
```

### ตั้งค่า LINE ต่อร้าน (ทำครั้งเดียวตอนรับลูกค้าใหม่)

1. สร้าง LINE Official Account + เปิด Messaging API ใน [LINE Developers Console](https://developers.line.biz)
2. เอา **Channel secret** และ **Channel access token** มาใส่ใน `data/tenants.json`
3. ตั้ง Webhook URL เป็น `https://<โดเมนของคุณ>/webhook/<tenantId>` และเปิด "Use webhook"
4. ปิด auto-reply เดิมของ LINE OA เพื่อไม่ให้ตอบซ้อนกับบอท
5. หา `ownerUserId` ของเจ้าของร้าน: ให้เจ้าของร้านทักแชทเข้ามา แล้วดู `userId` จาก log ของ webhook

เพิ่มร้านใหม่ = เพิ่ม 1 object ใน `tenants.json` แล้วรีสตาร์ต ไม่ต้องแตะโค้ด

## จุดที่ออกแบบมาเพื่อโมเดลธุรกิจ

- **ใช้ reply message เป็นหลัก** ซึ่งฟรีไม่จำกัดโควตาของ LINE — ร้านค้าไม่ต้องจ่ายแพ็กเกจ
  LINE OA แพงๆ ก็ใช้บอทได้ (push ใช้เฉพาะแจ้งเตือนเจ้าของร้านและแจ้งผลอนุมัติ)
- **โควตา freemium** (`monthlyOrderQuota`, ค่าเริ่มต้น 30 ออเดอร์/เดือน) — เกินแล้วบอทยังทำงาน
  ต่อ แต่แจ้งเจ้าของร้านให้อัปเกรดแพ็กเกจ เป็นกลไกขายอัตโนมัติในตัว
- **QR ล็อกยอด** ต่อออเดอร์ (dynamic PromptPay) — ลดปัญหาลูกค้าโอนผิดยอด และทำให้ตรวจสลิปง่าย
- **ช่องเสียบระบบตรวจสลิปอัตโนมัติ** อยู่ที่ `src/slipVerify.js` ที่เดียว — เมื่อต่อ API
  ตรวจสลิปจริง (เช่น SlipOK) ทุกร้านได้ฟีเจอร์นี้ทันที และขายเป็นแพ็กเกจแพงขึ้นได้
  ค่าเริ่มต้นคือให้เจ้าของร้านกดอนุมัติเอง (ปลอดภัยกว่า OCR ซึ่งโดนสลิปปลอมหลอกง่าย)

## โครงสร้างโค้ด

```
src/server.js      จุดรับ webhook (แยกตาม tenant) + endpoint รูป QR
src/flow.js        ตรรกะบทสนทนา: เมนู/ตะกร้า/ยืนยัน/สลิป/คำสั่งเจ้าของร้าน
src/line.js        เรียก LINE Messaging API + ตรวจลายเซ็น webhook
src/promptpay.js   สร้าง payload PromptPay ตามสเปก EMVCo (ไม่พึ่งไลบรารีภายนอก)
src/slipVerify.js  จุดต่อ API ตรวจสลิป (ตอนนี้เป็น manual approve)
src/store.js       เก็บข้อมูลเป็นไฟล์ JSON (ย้ายไป PostgreSQL ได้ — ทุก record มี tenantId)
```

## ขั้นต่อไปเมื่อเริ่มมีลูกค้าจ่ายเงิน

1. ย้าย `store.js` ไป PostgreSQL/SQLite (โครงสร้างข้อมูลพร้อมแล้ว)
2. ต่อ API ตรวจสลิปจริงใน `slipVerify.js` แล้วขายเป็นแพ็กเกจ Pro
3. ทำหน้าเว็บแอดมินให้ร้านแก้สินค้า/FAQ เอง (ตอนนี้แก้ผ่าน `tenants.json`)
4. ระบบเก็บเงินรายเดือนอัตโนมัติ + ระงับร้านที่ไม่ต่ออายุ
5. แจ้งเลขพัสดุ: เจ้าของร้านพิมพ์เลข tracking แล้วบอท push ให้ลูกค้า
