# สูตรคลิปป้ายยา Shopee Video: กฎพร้อมหลักฐาน

ที่มา: คลิป Shopee Video ภาษาไทย 4 คลิป ทุกคลิปได้ยอดวิวเกิน 20,000
- v1 `@fern.cute` กล่องเครื่องสำอาง 3 ชั้น (เนื้อหา 45.1 วิ)
- v2 `@mamiw.cosmo` ที่วางครก/หม้อร้อน ซื้อ 1 แถม 1 (20.1 วิ)
- v3 `@melodylotto` ไม้ถูพื้นแบบแผ่น + ทิชชูดักฝุ่น (31.9 วิ)
- v4 `@thanutthomyotha` ขวดน้ำมัน 2 in 1 (54.5 วิ)

วิธีวิเคราะห์
- ถอดเฟรมทุกวินาที ถอดเสียงด้วย Whisper large-v3 และหาช่วงที่มีเสียงพูดด้วย VAD (ตัวตรวจจับเสียงพูด)
- วิเคราะห์ 6 มุมมอง ได้กฎ 28 ข้อ แล้วให้ผู้ตรวจที่ตั้งใจจับผิดตรวจทีละข้อกับเฟรมและเสียงจริง
- ผลตรวจ: ยืนยันเต็ม 2 ข้อ, ยืนยันบางส่วน 25 ข้อ, ตกไป 1 ข้อ

## สารบัญ
1. Tier A: ด่านบังคับ (เจอครบ 4/4)
2. Tier B: ตัวเพิ่มแต้ม (เจอ 2–3/4 หรือยังพิสูจน์เหตุไม่ได้)
3. Tier C: ใช้ตามสถานการณ์
4. การเลือกสินค้า
5. สิ่งที่ไม่จำเป็น
6. กฎที่ตกไปหลังตรวจ

## 1. Tier A: ด่านบังคับ

### A1. เฟรมแรกคือสินค้ากำลังใช้งาน ไม่มีอินโทร ✅ ยืนยัน 4/4

ที่ 0.0 วิ ต้องเห็นสินค้าชัดกลางเฟรม กำลังถูกใช้หรือถูกหยิบจับ ณ จุดใช้งานจริง (โต๊ะเครื่องแป้ง เคาน์เตอร์ครัว พื้นห้อง เตา)

| คลิป | เฟรมแรก |
|---|---|
| v1 | มือยกกล่องเครื่องสำอางออกจากลังพัสดุบนโต๊ะเครื่องแป้ง |
| v2 | มือวางครกดินเผาคว่ำลงบนขาตั้งลวด ข้างหม้อหุงข้าว |
| v3 | ไม้ถูพื้นกำลังไถเลียบบัวผนัง ระดับพื้น |
| v4 | มือกดปั๊มขวดน้ำมันลงกระทะบนเตาแม่เหล็กไฟฟ้า |

- ห้ามเปิดด้วยสิ่งเหล่านี้
  - "สวัสดีค่ะ" การแนะนำตัวหรือชื่อช่อง
  - โลโก้ ภาพปก สไลด์ภาพนิ่ง ภาพแคตตาล็อก หรือสกรีนช็อต
  - หน้าคนพูดเปล่าๆ
- Shopee แนะนำเองว่าไม่ควรมีภาพนิ่งหรือแคตตาล็อกใน 5 วิแรก
- ทำไมน่าจะได้ผล: คนดูที่เลื่อนหาของรู้ทันทีว่าคลิปนี้ขายอะไร และน่าจะช่วยให้คนดูอยู่เกิน 3 วิ (effective view ใน Creator Center) แต่ยังไม่รู้ว่ายอดวิวสาธารณะนับแบบนี้หรือไม่ และคลิปวิวต่ำจำนวนมากก็เปิดแบบนี้ จึงเป็นขั้นต่ำ ไม่ใช่ตัวทำให้ปัง

### A2. ผลลัพธ์หรือจังหวะภาพใหม่ภายใน 2 วินาที (ช้าสุด 3.6 วิใน v4) ⚠️ ยืนยันบางส่วน (รูปแบบหลวมครบ 4/4 ภายในราว 4 วิ)

| คลิป | วินาที | สิ่งที่เห็น |
|---|---|---|
| v1 | 0.88 | ตัดไปกล่องที่จัดของเต็มแล้ว จากนั้นดึงลิ้นชักชั้น 1, 2, 3 ที่ 1.8 / 2.48 / 3.08 วิ |
| v2 | 1.12 | ยกขาตั้งขึ้นให้เห็นโครงลวด แล้ววางกระทะลงบนขาตั้งที่ราว 4.6 วิ |
| v3 | 1.72 | มุมบน ลอกแผ่นที่เต็มไปด้วยเส้นผมออกจากไม้ถู |
| v4 | 3.6 | สลับจากโหมดปั๊มไปเปิดฝาเท |

- แบบเข้ม คือ **โชว์ผลลัพธ์สุดท้ายก่อน แล้วค่อยย้อนไปเล่า** ชัดแค่ใน v1 และ v3 ซึ่งเป็นสินค้าแบบต้องผ่านขั้นตอนก่อนเห็นผล
- วิธีทำ: ถ่ายช็อตผลลัพธ์ตอนท้ายเก็บไว้ แล้วตัด 2–3 ช็อต ช็อตละ 0.6–1 วิ มาวางไว้ช่วง 0.5–3 วิ จากนั้นค่อยตัดกลับไปช่วงแกะกล่องหรือประกอบ
- ถ้าสินค้าไม่มีภาพก่อน/หลังใช้ (before/after) เช่น ขาตั้ง ขวด ให้เปิดกลางการใช้งานเลย ตัดเข้าภาพใกล้ผลลัพธ์ก่อน 2 วิ แล้วโชว์การใช้แบบที่ 2 ภายในราว 4–9 วิ

### A3. เริ่มพูดภายใน 0.3 วิ และประโยคแรกคือข้อมูลขาย ⚠️ ยืนยันบางส่วน (แกนหลักครบ 4/4)

คำแรกออกที่ 0.15 / 0.15 / 0.22 / 0.12 วิ ไม่มีคลิปไหนทักทาย ประโยคแรกของแต่ละคลิปเป็นแบบนี้

| คลิป | ประเภทประโยคแรก | ประโยค |
|---|---|---|
| v1 | หมวด + สเปก | "รีวิวกล่องใส่เครื่องสำอางแบบ 3 ชั้น…" |
| v2 | ดีลจริง + ชื่อสินค้า | "ต้องขอโทษบ้านไหนที่กดที่วางครกไปก่อนหน้านี้ด้วยนะคะ เพราะตอนนี้ทางร้านจัดโปรซื้อหนึ่งแถมหนึ่ง" |
| v3 | ผลลัพธ์ | "เก็บเส้นผม ฝุ่น ขนสัตว์ได้สะอาดมาก" |
| v4 | เงื่อนไข + ท่าใช้ | "ถ้าใครอยากเฮลตี้ น้ำมันน้อย ก็แค่ปั๊มลงไปสักสองสามปั๊มก็พอแล้วครับ" |

- ต้องพูดชื่อหมวดสินค้าที่คนใช้ค้นหาภายในราว 10–12 วิ (ครบ 4/4)
  - "ชื่อหมวด" คือคำที่คนพิมพ์ค้นใน Shopee เพื่อหาสินค้าตัวนี้หรือชิ้นหลักของชุด: v1 "กล่องใส่เครื่องสำอาง" (0.15 วิ), v2 "ที่วางครก" (~1 วิ), v3 "ทิชชูดักฝุ่น" (~9 วิ), v4 "ขวดสำหรับใส่น้ำมัน" (~10 วิ)
  - คำที่เรียกของเดิมที่สินค้ามาแทน (เช่น "ไม้ม็อบ" ใน v3) ไม่นับ
- เป้าหมายที่ดีกว่าคือพูดครบ "คืออะไร + เหมาะกับใคร + ได้อะไร" ภายใน 8–10 วิ (ทำได้ครบแค่ v3 กับ v4)

### A4. ข้อความหัวคลิปตั้งแต่เฟรมแรก ✅ ยืนยัน 4/4 (เป็นมาตรฐานทั่วไป ไม่ใช่ตัวเร่งยอดวิว)

| คลิป | ข้อความ | ขึ้นจอช่วง |
|---|---|---|
| v1 | กล่องใส่เครื่องสำอาง / แบบมีลิ้นชัก 3 ชั้น✅ | 0–3.84 วิ และกลับมาอีกครั้งที่ 35–45 วิ |
| v2 | ซื้อ 1 แถม 1 / ที่วางครก วางหม้อร้อนๆ | ตลอดคลิป |
| v3 | ลดเวลาไปเยอะ✨ / เส้นผม ฝุ่น ขนสัตว์ | 0–4.92 วิ |
| v4 | คุมน้ำมันทำอาหารได้ง่ายๆ | 0–9.2 วิ |

สเปกที่วัดได้จากทั้ง 4 คลิป
- ยาว 1–2 บรรทัด ประมาณ 5–9 คำ (รวมไม่เกินราว 40 ตัวอักษร)
- อยู่กึ่งกลางแนวนอน ในแถบ 10–30% จากขอบบน กว้างราว 50–60% ของจอ
  - ระวังอย่าให้ทับลายน้ำ Shopee Video ด้านซ้ายกลางจอ
- ตัวอักษรขาว ดำ หรือสีสด มีขอบตัดสี ไม่มีกล่องพื้นหลัง ไม่ทำแอนิเมชัน
- เนื้อหาเป็น "ป้ายบอกตรงๆ" แบบใดแบบหนึ่ง
  - ชื่อสินค้า + จุดเด่น
  - ดีล + ชื่อสินค้า
  - ประโยชน์ + 3 สิ่งที่จัดการได้
  - ประโยชน์ 1 ประโยค
- ทั้ง 4 คลิป**ไม่ใช้คำถาม ราคา หรือชื่อแบรนด์**
- ค้างอย่างน้อย 3 วิ (คลิปต้นแบบค้าง 3.84–9.2 วิ หรือตลอดคลิป จึงแนะนำราว 4 วิขึ้นไป) แล้วเอาข้อความออกตรงจุดตัดภาพที่เข้าสู่เนื้อหาช่วงกลาง (v1, v3, v4; v2 เป็นข้อความดีลจึงค้างตลอดคลิป)
- เสียงพากย์ควรพูดคีย์เวิร์ดเดียวกับข้อความหัวคลิปภายในราว 5 วิแรก

### A5. พากย์ต่อเนื่อง ไม่มีช่วงเงียบ ⚠️ ยืนยันบางส่วน (แกนหลักครบ 4/4)

- มีเสียงพูด 99.4 / 98.7 / 97.7 / 96.7% ของเวลาคลิป
- ความเร็วพูด (หลังแก้คำผิด) 19.0 / 18.3 / 18.1 / 17.0 ตัวอักษรไทยต่อวินาที
- เกณฑ์ผ่านตอนให้คะแนน (scorecard A5) คือไม่มีช่วงเงียบเกิน ~0.5 วิ ส่วน 0.25–0.3 วิในแบบ A ข้างล่างคือค่าที่ใช้ตอนตัดต่อ ซึ่งเข้มกว่าเพื่อเผื่อไว้
- มี 2 แบบที่ใช้ได้
  - **แบบ A เสียงพากย์ทับภาพ (v1–v3)**: อัดเสียงแยก ตัดช่วงหายใจหรือช่วงเงียบที่ยาวเกิน 0.25–0.3 วิ ออก แล้วตัดภาพตามเสียง
  - **แบบ B พูดหน้ากล้องสด (v4)**: เว้นจังหวะได้ไม่เกินราว 0.5 วิ แทรก B-roll (ภาพประกอบที่ตัดแทรกทับเสียงพูด) ได้ แต่เสียงพูดต้องต่อเนื่อง
- ใน CapCut ให้เช็กว่าเส้นคลื่นเสียงไม่มีช่วงแบนนานเกินที่กำหนด
- จบคลิปภายในราว 0.5 วิหลังคำสุดท้าย (v1, v2 ตัดตรงพยางค์สุดท้าย; v3 เงียบท้าย ~0.3–0.45 วิและไม่มี CTA; v4 เงียบท้าย ~0.6 วิ)
- ตารางนับตัวอักษร (17–19 ตัวอักษรต่อวินาที ไม่นับเว้นวรรค แต่นับสระบน-ล่างและวรรณยุกต์ทุกตัว เท่ากับ `len(script.replace(" ", ""))` ใน Python ตัวเลข 19.0 / 18.3 / 18.1 ของ v1–v3 นับแบบนี้ ถ้าไม่นับสระบน-ล่างและวรรณยุกต์ ตัวเลขจะต่ำลงราว 25% และเวลาที่คำนวณจะผิด)

### A6. ฟุตเทจของตัวเอง ถ่ายในบ้านจริง 9:16 ⚠️ ยืนยันบางส่วน (แกนหลักครบ 4/4)

- ถ่ายเองด้วยมือถือ แนวตั้งเต็มจอ ไม่มีขอบดำ ใช้ตัดชนล้วน
- ไม่มีภาพนิ่ง ภาพหน้าร้าน หรือลายน้ำแอปอื่น (ทั้ง 4 คลิปยาว 20–55 วิ)
- ตั้งกล้องไว้ระดับจุดใช้งานจริง
- ในเฟรมควรมีของใช้จริงที่ผ่านการใช้แล้ว เช่น สกินแคร์ที่ใช้อยู่ ครกเก่า หรือหม้อหุงข้าว
- บ้านดูสะอาด สว่าง โทนอ่อน แม้ปัญหาที่พูดถึงจะเป็นความรกหรือฝุ่น (เจอ 4/4 แต่ยังทดสอบไม่ได้ว่าเป็นเหตุ)
- ทำไมสำคัญ: เป็นเงื่อนไขของโครงการ **Original Creator** ที่ให้ค่าคอมเพิ่ม
  - โครงการนี้ยอมรับ "มือหรือเสียง" เป็นตัวตนของครีเอเตอร์ จึงไม่ต้องโชว์หน้า
  - เลี่ยงสิ่งที่ Shopee ไม่สนับสนุน คือภาพนิ่ง สไลด์ และการรีโพสต์

### A7. สินค้าเดียวต่อคลิป ยาว 15–60 วิ (ครบ 4/4) และติดตะกร้าส้ม (ข้อบังคับของ Original Creator; ตรวจจากไฟล์คลิปไม่ได้)

- คลิปละ 1 สินค้า (1 SKU) ไม่ทำแนวขนของหลายชิ้น, Top 5 หรือเปรียบเทียบ
- ทุกประโยคและทุกช็อตชี้ไปที่สินค้าเดียวกัน
- ความยาวที่แนะนำคือ 20–45 วิ
  - v4 ที่ยาว 54.5 วิ ถูกประเมินว่ายืดและซ้ำเกินไป แม้จะยังได้ 20k+

### A8. ทุกคำกล่าวอ้างต้องเป็นจริง (ข้อบังคับด้านจริยธรรม)

- โปรและระยะเวลา เช่น "แค่ 3 วัน" ต้องเป็นจริงตามหน้าร้าน
- "ซื้อมาใช้เอง" ต้องซื้อจริง และ "ตรงปก" ต้องมีภาพพิสูจน์
- ไม่อ้างสรรพคุณสุขภาพเกินจริง
- ถ้าใช้เสียง AI ต้องติดป้ายตามกฎ Shopee

## 3. Tier C: ใช้ตามสถานการณ์

- **ดีลจริงเป็นตัวเปิด** (v2)
  - เปิดด้วย "ต้องขอโทษบ้านไหนที่กด[สินค้า]ไปก่อนหน้านี้ เพราะตอนนี้ร้านจัดโปร…"
  - ข้อความดีลค้างไว้ตลอดคลิป แล้วพูดดีลซ้ำพร้อมกำหนดเวลาจริงก่อน CTA
  - **ใช้ได้เฉพาะตอนมีโปรจริงเท่านั้น**
  - โปรใหม่ของสินค้าที่เคยขายดีเป็นเหตุผลที่ดีในการทำคลิปใหม่
- **ข้อความหัวคลิปกลับมาตอน CTA** (v1) หรือค้างตลอดคลิป (v2) ช่วยให้คนที่ปิดเสียงดูรู้ว่าจะกดซื้ออะไร

- **ชวนซื้อของสิ้นเปลืองคู่กัน** เช่น v3 พูด "แนะนำให้กดไปพร้อมทิชชูเปียกของเขาเลย" ข้อนี้ช่วยยอดขาย ไม่ได้ช่วยยอดวิว

## 4. การเลือกสินค้า (ทำก่อนถ่ายทุกครั้ง)

ทั้ง 4 คลิปเป็นของ Home & Living ราคาไม่สูง (ราคาประมาณการ ยังไม่ได้ตรวจหน้าร้าน)
- v1 กล่องเครื่องสำอาง ราว ฿199–350
- v2 ที่วางครก ราว ฿59–149 ต่อชุด 1+1
- v3 ไม้ถูพื้น + แผ่นดักฝุ่น ราว ฿99–259
- v4 ขวดน้ำมัน ราว ฿99–159

เช็กลิสต์ก่อนรับสินค้ามารีวิว
1. แก้ปัญหาเล็กๆ ที่เกิดซ้ำทุกวันหรือทุกสัปดาห์ และพูดปัญหาจบได้ใน 1 ประโยค เช่น
   - "เครื่องสำอางเยอะจนไม่มีที่เก็บ"
   - "ครกเหม็นอับ"
   - "ผม ฝุ่น ขนสัตว์เต็มพื้น"
   - "เทน้ำมันเยอะเกิน"
2. **มีผลลัพธ์ที่กล้องจับได้ภายใน 3 วิ** เช่น ลิ้นชักเต็ม แผ่นที่มีผมติด สายน้ำมัน ครกวางพอดี
   - ถ้าประโยชน์หลักมองไม่เห็น (กลิ่น ความทน) ให้พยายามหาภาพแทน ถ้าหาไม่ได้ ให้ใช้ดีลจริงหรือช็อตใช้งานแทนแบบ v2 (ซึ่งไม่มีภาพพิสูจน์แต่ก็ได้ 20k+)
3. ถ่ายคู่กับของที่คนไทยมีแทบทุกบ้านได้ (ครก หม้อหุงข้าว กระทะ สกินแคร์ร้านยา) คนดูจะเข้าใจทันทีว่าใช้ในบ้านตัวเองได้
4. ราคาระดับตัดสินใจเร็ว ไม่ต้องเลือกไซซ์หรือสี และสเปกไม่ซับซ้อน (ถ้าร้านมีหลายไซซ์ ไม่ต้องตัดสินค้าทิ้ง แต่ให้ติดตะกร้ารุ่นที่ถ่ายจริงและบอกขนาดในคลิป)
   - ถ้าต้องติดตั้ง (เจาะผนัง กาว สกรู) ให้เช็กว่าผู้ใช้ติดตั้งได้จริง เช่น กฎนิติบุคคลคอนโดหรือห้องเช่า และห้ามพูดว่า "ไม่ต้องเจาะ" ถ้าไม่จริง
5. เช็กสัญญาณจากหน้าร้าน: ยอดขาย เรตติ้ง โปรหรือโค้ดที่กำลังมี และค่าคอมมิชชัน
6. ถ้าใช้ได้ 2 แบบ หรือตัดขั้นตอนเดิมได้ จะได้แต้ม B6 เพิ่ม แต่ไม่บังคับ

## 6. กฎที่ตกไปหลังตรวจ (อย่าเอาไปสอน)

- "ต้องเป็นของไอเดียแปลกใหม่ มีกลไกเจ๋ง": มีจริงแค่ v4 (ตกไป)
- "3 วิแรกต้องตัดถี่ที่สุดในคลิป": จริงแค่ v1 และ v2 ส่วน v3 ช่วงท้าย (24–30 วิ) เคลื่อนไหวมากกว่าช่วงเปิด และ v4 ช่วง 0–3 วิอยู่แค่อันดับ 5 จาก 18 ช่วง
- "ต้องมีตัวเลขสเปกในคลิป": v3 ไม่มีตัวเลขเลยแต่ก็ได้ 20k+
- "ภาพสุดท้ายต้องวนกลับมาเหมือนเฟรมแรก (loop)": ไม่มีหลักฐาน และยังไม่ยืนยันว่า Shopee เล่นคลิปวนเอง
- "บัญชีที่โพสต์บ่อยคือสาเหตุ": ดูจากตัวคลิปไม่ได้ ให้ย้ายไปไว้ในหัวข้อปัจจัยนอกคลิป
