# plan.json: แผนตัดต่อสำหรับ `build_video.py`

path ทุกตัวนับจากโฟลเดอร์ที่ plan.json อยู่ วิดีโอที่ได้คือ 1080×1920, 30 fps, H.264 (สี BT.709) + AAC

## โครงสร้าง

```json
{
  "output": "out/final.mp4",
  "voice": {"tempo": "auto"},
  "headline": {"lines": ["บรรทัดบน", "บรรทัดล่าง"]},
  "beats": [
    {"name": "hook", "text": "[excited] ประโยคที่ส่งให้ ElevenLabs", "audio": "vo/01.mp3",
     "shots": [{"src": "media/ai_use.mp4", "start": 1.5, "ai": true, "in_use": true, "dur": 1.4},
               {"src": "input/product.jpg", "motion": "push_in"}]}
  ],
  "labels": []
}
```

## ฟิลด์

**ระดับบนสุด**

| ฟิลด์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `output` | `"out/final.mp4"` | ไฟล์ผลลัพธ์ |
| `width`, `height`, `fps` | 1080, 1920, 30 | ไม่ต้องเปลี่ยน |
| `font_dir` | `assets/fonts` ของ skill | โฟลเดอร์ฟอนต์ |

**voice**

| ฟิลด์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `tempo` | `"auto"` | `"auto"` = เร่งเสียงให้ได้ `target_cps` ตัวอักษร/วิ (นับจาก `text` ของ beat ที่มีข้อความ ไม่นับแท็ก เว้นวรรค และ beat ที่ไม่มีข้อความ) หรือใส่ตัวเลข 0.25–4.0 เช่น `1.25` |
| `target_cps` | 17.0 | ความเร็วพูดเป้าหมาย |
| `max_tempo` | 1.45 | เร่งได้สูงสุดกี่เท่า (สูงกว่านี้เสียงเริ่มไม่เป็นธรรมชาติ) |
| `gap` | 0.08 | ช่วงเงียบระหว่าง beat (วินาที) ห้ามเกิน 0.3 |
| `lead_in` | 0.1 | ช่วงเงียบก่อนคำแรก ต้องไม่เกิน 0.3 (A3) |
| `tail` | 0.2 | ช่วงเงียบหลังคำสุดท้าย ภาพยังเล่นต่อในช่วงนี้ |
| `trim_db` | -55 | ระดับเสียงที่ถือว่าเงียบตอนตัดหัวท้ายแต่ละ beat (dB) |
| `loudness` | -14 | ความดังเป้าหมาย (LUFS) ปรับแบบ 2 รอบให้ตรงเป้า |

**headline** (ข้อความหัวคลิป)

| ฟิลด์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `lines` | – | 1–2 บรรทัด ราว 5–9 คำ ไม่ใส่อีโมจิ |
| `end` | `"auto"` | `"auto"` = เอาออกตรงจุดตัดภาพแรกที่เลย `min_end` วิ หรือใส่วินาที ถ้าเป็นข้อความดีลที่ต้องค้างทั้งคลิปให้ใส่ `999` |
| `min_end` | 3.5 | ต่ำสุดที่ยอมให้ข้อความหาย |
| `repeat_in_last_beat` | false | ให้ข้อความกลับมาตอน CTA (ประโยคชวนกดตะกร้าท้ายคลิป) เป็นเทคนิค Tier C |
| `sizes` | อัตโนมัติ | ไม่ต้องใส่ ระบบคำนวณให้บรรทัดแรกกว้างราว 50% ของจอ (ใหญ่สุด 120) บรรทัดสองเล็กกว่าเล็กน้อย ถ้าจะกำหนดเองให้ใส่เช่น `[110, 90]` |
| `top` | 0.11 | ระยะจากขอบบน (สัดส่วนความสูงจอ) ถ้าตัวหนังสือทับสินค้าในช็อตแรก ให้ลดเหลือ 0.08–0.09 หรือเลือกช็อตที่สินค้าอยู่ต่ำลง |
| `colors`, `font`, `outline` | ["FFFFFF","FFE14D"], "Kanit", 6 | สี (RGB hex) ฟอนต์ และความหนาขอบ |

**beats[]**: 1 beat = 1 ประโยคพากย์ = 1 ไฟล์เสียง

| ฟิลด์ | ความหมาย |
|---|---|
| `text` | ข้อความที่ส่งให้ ElevenLabs (ใส่แท็กได้) ใช้คำนวณความเร็วและทำไฟล์ .srt |
| `audio` | ไฟล์เสียงของ beat นี้ ถ้าไฟล์เงียบหรือเบาเกินไป สคริปต์จะหยุดและบอก |
| `shots[]` | ภาพที่เล่นระหว่างพูดประโยคนี้ เรียงตามลำดับ (ต้องมีอย่างน้อย 1) |

**shots[]**

| ฟิลด์ | ใช้กับ | ความหมาย |
|---|---|---|
| `src` | ทุกแบบ | ภาพนิ่ง (`.jpg .png .webp .bmp .tif .heic` …) หรือวิดีโอ |
| `dur` | ทุกแบบ | ความยาวตายตัว (วินาที) |
| `weight` | ทุกแบบ | สัดส่วนของเวลาที่เหลือ (ค่าเริ่มต้น 1) |
| `in_use` | ทุกแบบ | ช็อตนี้เป็นสินค้ากำลังใช้งานไหม (qa_check ใช้ตรวจ A1) วิดีโอมีค่าเริ่มต้นเป็น `true` ถ้าวิดีโอไม่ใช่ตอนใช้งาน เช่น หมุนโชว์กล่อง ให้ใส่ `false` ส่วนภาพนิ่งจะไม่ผ่าน A1 เสมอ |
| `ai` | ทุกแบบ | `true` ถ้าสร้างด้วย AI |
| `setup` | ทุกแบบ | ชื่อมุมกล้อง (ไม่บังคับ) ใช้นับความหลากหลายของมุมใน `qa_check.py` ถ้าไม่ใส่ จะนับ 1 ไฟล์ = 1 มุม และไฟล์ที่ภาพแรกแทบเหมือนกันนับเป็นมุมเดียว ให้ใส่เมื่อไฟล์วิดีโอเดียวมีหลายมุม เช่น `"setup": "top"` กับ `"setup": "side"` |
| `start` | วิดีโอ | เริ่มจากวินาทีที่เท่าไรของไฟล์ (คลิป AI ให้ข้ามวินาทีแรกที่มักนิ่ง) ถ้าเกินความยาวคลิป สคริปต์จะหยุดและบอก |
| `speed` | วิดีโอ | 1.0 = ปกติ ถ้าคลิปสั้นกว่าช็อต จะค้างเฟรมสุดท้าย |
| `fit` | ทั้งสองแบบ | `cover` = ครอปให้เต็มจอ (ค่าเริ่มต้นของวิดีโอ) / `fit` = เห็นทั้งภาพ / `auto` (ค่าเริ่มต้นของภาพนิ่ง) |
| `motion` | ภาพนิ่ง | `push_in`, `pull_out`, `pan_left`, `pan_right`, `pan_up`, `pan_down`, `still` |
| `z`, `fx`, `fy` | ภาพนิ่ง | กำหนดการเคลื่อนกล้องเอง (ดูข้างล่าง) |

**วิธีแบ่งเวลาในแต่ละ beat**
- ช็อตที่มี `dur` ได้เวลาตามนั้น ช็อตที่ไม่มีจะแบ่งเวลาที่เหลือตาม `weight`
- ถ้าทุกช็อตมี `dur` ช็อตสุดท้ายจะถูกยืดหรือหดให้จบพอดีกับ beat
- ถ้า `dur` รวมกันเกินเวลาของ beat หรือเหลือให้ช็อตอื่นไม่ถึง 0.3 วิ สคริปต์จะย่อทุกช็อตให้พอดีและเตือนใน stderr
- ภาพจึงตัดตรงจุดเริ่มประโยคถัดไปเสมอ

**`fit: auto` กับภาพนิ่ง**
- **ภาพสัดส่วนใกล้ 9:16** (กว้าง÷สูง 0.5–0.65): ครอปเต็มจอ
- **ภาพสินค้าพื้นขาวหรือพื้นสีเรียบ (packshot)**: ครอปให้เหลือตัวสินค้า ขยาย แล้ววางบนพื้นสีเดียวกันแบบขอบกลืน
- **ภาพถ่ายทั่วไป** (เช่น ภาพมือถือ 3:4 หรือภาพ 1:1): เห็นทั้งภาพ บนพื้นเบลอสีเข้มของภาพเดียวกัน

**การเคลื่อนกล้องเอง**
- `z` = [ซูมเริ่ม, ซูมจบ]
- `fx`, `fy` = [จุดกึ่งกลางเริ่ม, จบ] เป็นสัดส่วน 0–1 ของ**เฟรม 9:16 หลังจัดภาพแล้ว** ไม่ใช่ของภาพต้นฉบับ
  - ใช้ `python3 build_video.py --frame <ภาพ> check.jpg` เพื่อดูเฟรมที่จัดแล้ว แล้ววัดตำแหน่งจากภาพนั้น (ภาพกว้าง 1080 สูง 1920)
- ตัวอย่าง: ซูมเข้าฝาขวดที่อยู่สูงกลางจอ `{"z":[1.2,1.8],"fx":[0.5,0.5],"fy":[0.45,0.38]}`
- ระบบจะดันจุดกึ่งกลางเข้ามาเองถ้าเลยขอบ ภาพจึงไม่ค้าง

**labels[]** (ไม่บังคับ): ข้อความเสริม เช่น ชื่อชิ้นส่วน
- `{"text":"ซีลกันอากาศ","start":12.0,"end":14.0,"x":0.5,"y":0.7,"size":64,"color":"FFFFFF"}`
- ใช้ไม่บ่อย คลิปต้นแบบไม่มีป้ายแบบนี้เลย

## หลักจัดช็อตให้ผ่านสูตร

- **beat แรก**: ช็อตแรกเป็นสินค้ากำลังใช้งาน `dur` 1.0–1.5 วิ แล้วตัดไปช็อตผลลัพธ์หรือช็อตเด่นภายใน 2 วิ
- **ภาพนิ่ง**: ช็อตละ 1–2.5 วิ ใช้ motion ต่างกันในช็อตที่ติดกัน และพยายามให้ภาพนิ่งรวมไม่เกิน 20%
- **beat ที่พูดถึงชิ้นส่วน**: ใช้ภาพใกล้ชิ้นนั้น (ใช้ `z`/`fx`/`fy` ซูมเข้า)
- **มุมกล้อง** (ดู `shot-list.md`): คลิป 30 วิต้องมีราว 8 มุม มุมเดียวไม่เกิน 30% ของเวลา
  - ใช้ทุกไฟล์ที่มีก่อนจะวนกลับไปไฟล์เดิม และอย่าวางช็อตจากไฟล์เดียวกันติดกัน ยกเว้นตั้งใจทำ jump cut
  - การครอปหรือซูมภาพนิ่งเดิมไม่นับเป็นมุมใหม่ คนดูยังเห็นเป็นภาพเดิม
- **คลิปเดียวใช้หลายช็อตได้** ด้วย `start` ต่างกัน ให้เป็นช่วงที่ยังไม่เคยโชว์ ภาพที่โชว์ซ้ำทั้งคลิปควรไม่เกิน 15%
- **beat สุดท้าย (CTA)**: ภาพยังเป็นการใช้งานจริง ไม่ใช้การ์ดปิด
