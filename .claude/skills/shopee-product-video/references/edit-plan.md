# plan.json: แผนตัดต่อสำหรับ `build_video.py`

path ทุกตัวนับจากโฟลเดอร์ที่ plan.json อยู่ วิดีโอที่ได้คือ 1080×1920, 30 fps, H.264 + AAC

## โครงสร้าง

```json
{
  "output": "out/final.mp4",
  "voice": {"tempo": "auto", "target_cps": 17.5, "max_tempo": 1.35, "gap": 0.08, "lead_in": 0.1, "tail": 0.2, "loudness": -14},
  "headline": {"lines": ["บรรทัดบน", "บรรทัดล่าง"], "end": "auto", "min_end": 3.5, "repeat_in_last_beat": false},
  "beats": [
    {"name": "hook", "text": "[excited] ประโยคที่ส่งให้ ElevenLabs", "audio": "vo/01.mp3",
     "shots": [{"src": "media/ai_use.mp4", "ai": true, "in_use": true, "dur": 1.4},
               {"src": "input/product.jpg", "motion": "push_in"}]}
  ],
  "labels": []
}
```

## ฟิลด์

**voice**

| ฟิลด์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `tempo` | `"auto"` | `"auto"` = เร่งเสียงให้ได้ `target_cps` ตัวอักษร/วิ (นับจาก `text` ของทุก beat ไม่นับแท็กและเว้นวรรค) เร่งได้ 1.0 ถึง `max_tempo` เท่า หรือใส่ตัวเลข เช่น `1.25` |
| `gap` | 0.08 | ช่วงเงียบระหว่าง beat (วินาที) ห้ามเกิน 0.3 |
| `lead_in` | 0.1 | ช่วงเงียบก่อนคำแรก ต้องไม่เกิน 0.3 ตามเกณฑ์ A3 |
| `tail` | 0.2 | ช่วงเงียบหลังคำสุดท้าย ภาพยังเล่นต่อในช่วงนี้ |
| `loudness` | -14 | ความดังเป้าหมาย (LUFS) |

**headline**: ข้อความหัวคลิป

| ฟิลด์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `lines` | – | 1–2 บรรทัด ราว 5–9 คำ ไม่ใส่อีโมจิ |
| `end` | `"auto"` | `"auto"` = เอาข้อความออกตรงจุดตัดภาพแรกที่เลย `min_end` วิ หรือใส่วินาที (ข้อความดีลให้ค้างตลอดคลิปด้วยการใส่ความยาวคลิป) |
| `min_end` | 3.5 | ต่ำสุดที่ยอมให้ข้อความหาย |
| `repeat_in_last_beat` | false | ให้ข้อความกลับมาตอน CTA (Tier C) |
| `sizes`, `colors`, `top`, `font` | [104, 84], ["FFFFFF","FFE14D"], 0.12, "Kanit" | ขนาดตัวอักษร สี (RGB hex) และระยะจากขอบบน (สัดส่วนความสูงจอ) |

**beats[]**: 1 beat = 1 ประโยคพากย์ = 1 ไฟล์เสียง

| ฟิลด์ | ความหมาย |
|---|---|
| `text` | ข้อความที่ส่งให้ ElevenLabs (ใส่แท็กได้) ใช้นับความเร็วพูดและทำไฟล์ .srt |
| `audio` | ไฟล์เสียงของ beat นี้ |
| `shots[]` | ภาพที่เล่นระหว่างพูดประโยคนี้ เรียงตามลำดับ เวลาของ beat จะแบ่งให้ shot ตาม `dur` (วินาที) หรือตาม `weight` |

**shots[]**

| ฟิลด์ | ใช้กับ | ความหมาย |
|---|---|---|
| `src` | ทุกแบบ | `.jpg/.png/.webp` = ภาพนิ่ง, ไฟล์อื่น = วิดีโอ |
| `dur` / `weight` | ทุกแบบ | ความยาวตายตัว หรือสัดส่วนของเวลาที่เหลือ (ค่าเริ่มต้น weight=1) |
| `in_use` | ทุกแบบ | ใส่ `true` ถ้าช็อตนี้เป็นสินค้ากำลังใช้งาน (qa_check ใช้ตรวจ A1) |
| `ai` | ทุกแบบ | ใส่ `true` ถ้าสร้างด้วย AI (qa_check จะเตือนให้ติดป้าย AI) |
| `start` | วิดีโอ | เริ่มตัดจากวินาทีที่เท่าไรของไฟล์ |
| `speed` | วิดีโอ | 1.0 = ปกติ, 1.5 = เร็วขึ้น ถ้าคลิปสั้นกว่าช็อต สคริปต์จะค้างเฟรมสุดท้ายไว้ |
| `fit` | ทั้งสองแบบ | `cover` = ครอปให้เต็มจอ, `fit` = เห็นทั้งภาพบนพื้นเบลอ, `auto` (ภาพนิ่ง) = ภาพแนวตั้งใช้ครอป ภาพอื่นใช้พื้นเบลอ |
| `motion` | ภาพนิ่ง | `push_in`, `pull_out`, `pan_left`, `pan_right`, `pan_up`, `pan_down`, `still` |
| `z`, `fx`, `fy` | ภาพนิ่ง | กำหนดการเคลื่อนกล้องเอง: `z` = [ซูมเริ่ม, ซูมจบ], `fx`/`fy` = [จุดกึ่งกลางเริ่ม, จบ] เป็นสัดส่วน 0–1 เช่น ซูมเข้าหาฝาขวดด้านขวาบน `{"z":[1.1,1.6],"fx":[0.5,0.62],"fy":[0.5,0.35]}` |

**labels[]** (ไม่บังคับ): ข้อความเสริม เช่น ชื่อชิ้นส่วน `{"text":"ซีลกันอากาศ","start":12.0,"end":14.0,"x":0.5,"y":0.7,"size":64,"color":"FFFFFF"}`
- ใช้ไม่บ่อย คลิปต้นแบบไม่มีซับวิ่งหรือป้ายชิ้นส่วนเลย

## หลักจัดช็อตให้ผ่านสูตร

- **beat แรก**: ช็อตแรกเป็นสินค้ากำลังใช้งาน `dur` 1.0–1.5 วิ แล้วตัดไปช็อตผลลัพธ์หรือช็อตเด่นภายใน 2 วิ
- **ภาพนิ่ง**: ช็อตละ 1–2.5 วิ ใช้ motion ต่างกันในช็อตที่ติดกัน และอย่าให้ภาพนิ่งรวมเกิน 20% ถ้าทำได้
- **beat ที่พูดถึงชิ้นส่วน**: ใช้ภาพใกล้ชิ้นนั้น เช่น `z`/`fx`/`fy` ซูมเข้าหาจุดนั้นในภาพ
- **beat สุดท้าย (CTA)**: ภาพยังเป็นการใช้งานจริง ไม่ใช้การ์ดปิด
