# สูตรคลิปป้ายยา (ฉบับย่อจาก skill shopee-viral-clip)

ที่มาของสูตรคือคลิป Shopee Video ภาษาไทย 4 คลิปที่ได้ยอดวิวเกิน 20,000 และไม่มีคลิปวิวต่ำมาเทียบ จึงเป็น "มาตรฐานที่คลิปปังทำครบ" ไม่ใช่การันตียอดวิว
ถ้ามี skill `shopee-viral-clip` ให้อ่านฉบับเต็ม (`references/formula.md`, `script-templates.md`, `scorecard.md`)

## สูตร 0–2–3

| เวลา | ต้องเกิด |
|---|---|
| 0.0 วิ | สินค้ากำลังใช้งาน ณ ที่ใช้จริง + ข้อความหัวคลิป + เสียงพูดเริ่มภายใน 0.3 วิ และประโยคแรกเป็นข้อมูลขาย (ไม่ทักทาย) |
| ≤ 2 วิ | ตัดไปภาพใหม่ที่เป็นผลลัพธ์หรือจุดเด่น (ช้าสุดราว 4 วิ) |
| ≤ 3 วิ | คนดูรู้ว่าสินค้าคืออะไรและได้อะไร |

ส่วนที่เหลือของคลิป
- พากย์ต่อเนื่องไม่มีช่วงเงียบเกิน 0.5 วิ
- พูดถึงอะไร ภาพต้องโชว์สิ่งนั้น
- หยิบสินค้าขึ้นมาหมุนหรือแกะให้ดู
- พิสูจน์ผลลัพธ์ซ้ำ 2–3 ครั้ง
- จบขณะภาพยังเป็นการใช้งาน และประโยคสุดท้ายบอกทางซื้อ

| ข้อ | เกณฑ์ |

| A2 | ภาพใหม่หรือผลลัพธ์ภายใน 2 วิ |

| A4 | ข้อความหัวคลิป 1–2 บรรทัดตั้งแต่เฟรมแรก ค้าง ≥3 วิ |

| A8 | ทุกคำกล่าวอ้างเป็นจริง และติดป้าย AI ถ้าใช้เสียงหรือภาพ AI |

## hook 4 แบบ

| แบบ | ใช้กับ | 0–5 วิ |
|---|---|---|
| A โชว์ผลลัพธ์ก่อน | จัดระเบียบ ประกอบ | ช็อตสินค้าเปล่า 0.9 วิ → ตัดเร็วไปภาพผลลัพธ์ 2–3 ช็อต → ย้อนกลับไปเล่า |
| B ดีลจริงเป็นตัวเปิด | มีโปรจริงที่มีวันหมดเขต | ข้อความดีลค้างตลอดคลิป + "ต้องขอโทษบ้านไหนที่กด[สินค้า]ไปก่อนหน้านี้ เพราะตอนนี้ร้านจัดโปร…" |
| C เผยคราบหรือหลักฐาน | ทำความสะอาด ดักจับสิ่งสกปรก | สินค้ากำลังทำงาน → มุมบนยกสิ่งสกปรกที่เก็บได้ขึ้นมาให้เห็นชัด |
| D สาธิต 2 โหมด | ใช้ได้ 2 แบบ | "ถ้าใครอยาก[ผล 1] ก็แค่[ท่า 1]…" → ตัดภาพตรงคำว่า "แต่" → "ถ้าต้องการ[ผล 2] ก็แค่[ท่า 2]" |

## โครงสคริปต์ (1 บรรทัด = 1 beat)

1. **เปิด** (0–3 วิ) ใช้ 1 แบบ
   - "รีวิว[หมวด]แบบ[สเปก] สำหรับใครที่[ปัญหา]อย่างเราเนี่ย"
   - "[ผลลัพธ์ที่เห็นได้]ได้สะอาดมาก"
   - "ถ้าใครอยาก[ผลลัพธ์] ก็แค่[ท่าใช้]ก็พอ"
2. **ใคร + ปัญหา หรือความคุ้ม**
   - "คือถ้าเป็นคน[นิสัย] ตัวนี้คือตอบโจทย์มาก"
   - "ไม่ต้อง[ขั้นตอนเดิม 1] ไม่ต้อง[ขั้นตอนเดิม 2]"
   - "ใช้[A]ได้ [B]ได้ ได้หมดเลย"
3. **ชื่อหมวดที่คนค้น**: "ตัวนี้จะเป็น[หมวด]…" (พูดก่อนวินาทีที่ 12)
4. **ฟีเจอร์ → ประโยชน์ 2–3 ข้อ**
   - "เราชอบตรงที่เขามี[ฟีเจอร์]มาให้ ทำให้[ประโยชน์]"
   - "ตรง[ชิ้นส่วน]เขาจะมี[ฟีเจอร์]มาให้ [ประโยชน์]"
5. **ข้อกังวล 1 ข้อพร้อมภาพพิสูจน์**: "ตอนแรกก็แอบกลัวว่า[ข้อกังวล] แต่…" (ใช้เมื่อเป็นประสบการณ์จริงเท่านั้น)
6. **พูดประโยคขายหลักซ้ำ** ด้วยคำเดิม
7. **ปิด**
   - "ใครที่[ปัญหาเดิม] คือแนะนำเลย"
   - "พิกัดแปะไว้ให้ที่เดิม กดตะกร้าได้เลยค่ะ" ต้องเป็นประโยคสุดท้าย และไม่พูดบ๊ายบาย ขอบคุณ หรือขอให้ฟอลโลว์

คำเปิดที่ห้ามใช้: "สวัสดีค่ะ" "วันนี้จะมารีวิว…" หรือคำถามลอยๆ ที่ไม่บอกว่าสินค้าคืออะไร

## ไม่จำเป็น (คลิปต้นแบบต่างกันในเรื่องนี้แต่ได้ 20k+ เหมือนกัน)

หน้าคน, ราคาในคลิป, ชื่อแบรนด์, ซับวิ่ง, เพลงประกอบ, ภาพ "ก่อนใช้", ตัดถี่ทั้งคลิป
