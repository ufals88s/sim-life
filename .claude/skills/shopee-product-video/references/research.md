# ค้นข้อมูลสินค้า

เป้าหมายคือหาข้อมูลที่ "พูดในคลิปได้อย่างมั่นใจ" ไม่ใช่รวบรวมทุกอย่าง ให้จบใน 5–10 คำค้น

## เครื่องมือ

- **WebSearch**: โหลดด้วย `ToolSearch "select:WebSearch,WebFetch"` แล้วค้นทั้งภาษาไทยและอังกฤษ
- **WebFetch**: มักถูกบล็อกในสภาพแวดล้อมคลาวด์ และหน้า Shopee เป็น JavaScript จึงอ่านตรงๆ ไม่ได้
  - ถ้าต้องใช้ข้อมูลหน้าร้าน ให้ขอ **ภาพหน้าจอหน้าสินค้า** จากผู้ใช้ แล้วอ่านจากภาพ ได้ราคา โปร ยอดขาย เรตติ้ง และสเปก
- **ภาพสินค้า**: อ่านข้อความบนกล่องหรือฉลากก่อนเสมอ เป็นแหล่งที่น่าเชื่อที่สุด

## คำค้นที่ใช้ (แทน <หมวด> ด้วยชื่อที่คนค้นจริง)

1. `<หมวด> รีวิว ข้อดี ข้อเสีย` และ `<category> review pros cons`
2. `<หมวด> ใช้ยังไง` / `<category> how to use`
3. `<หมวด> shopee ราคา` (ใช้ดูช่วงราคาเท่านั้น)
4. `<หมวด> ปัญหา` / `<category> common problems` (ใช้หาข้อกังวลที่ต้องตอบในคลิป)
5. ถ้ามียี่ห้อหรือรุ่น: `<ยี่ห้อ รุ่น> สเปก` / `<brand model> specifications`

## กติกาการใช้ข้อมูลในสคริปต์

| ประเภทข้อมูล | พูดในคลิปได้เมื่อ |
|---|---|
| สเปก (ขนาด ความจุ วัสดุ จำนวนชิ้น) | มาจาก `[ภาพ]` `[ผู้ใช้]` `[หน้าร้าน]` หรือ `[เว็บ: URL]` ที่เป็นหน้าทางการของยี่ห้อและรุ่นเดียวกับในภาพเท่านั้น ข้อมูลจากเว็บของสินค้าคนละรุ่นหรือร้านทั่วไปใช้ไม่ได้ |
| ราคา โปร ระยะเวลาโปร | มาจาก `[ผู้ใช้]` หรือ `[หน้าร้าน]` ที่มีวันที่ และควรเลี่ยงพูดราคาในเสียง (ราคาเปลี่ยนบ่อย) |
| ประโยชน์ทั่วไปของหมวดสินค้า | เจอใน `[เว็บ]` อย่างน้อย 2 แหล่ง หรือเห็นได้ชัดจากการใช้งาน |
| สรรพคุณสุขภาพ ความปลอดภัย "ฆ่าเชื้อ" "ไม่มีสารพิษ" | ต้องมีบนฉลากหรือหน้าร้านเท่านั้น และพูดตามคำบนฉลาก ห้ามขยาย |
| ประสบการณ์ส่วนตัว ("ใช้มา 1 เดือน" "ซื้อมาเอง" "เราชอบตรงที่…") | ผู้ใช้ยืนยันว่าจริงเท่านั้น ถ้าไม่จริงให้พูดแบบ "ตัวนี้…" หรือ "สำหรับใครที่…" |

## แม่แบบ `research/brief.md`

```markdown
# <ชื่อสินค้า> (หมวดที่คนค้น: <...>)
ยี่ห้อ/รุ่น: <... หรือ "ไม่ทราบ">

## ปัญหาที่แก้ (1 ประโยคที่คนดูพูดเอง)
- "<...>" [เว็บ: url]

## ฟีเจอร์ → ประโยชน์
- <ฟีเจอร์> → <ประโยชน์> [ภาพ]
- ...

## ข้อกังวลอันดับ 1 ของคนซื้อ + คำตอบ (ต้องโชว์ด้วยภาพได้)
- <...> → <...> [หน้าร้าน]

## ช่วงราคาในตลาด (ข้อมูลภายใน ไม่ต้องพูดในคลิป)
- ฿<...>–<...> [เว็บ: url, วันที่]

## คำค้นที่คนใช้ (ใช้ทำแคปชันและแฮชแท็ก)
- <...> [เว็บ: url]

## สิ่งที่ห้ามพูด / ยังไม่ยืนยัน
- <...>
```
